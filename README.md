**MealMuse**: A meal idea generator for your groceries

_Project Overview_:

i) User enters one or more ingredients or keywords.  
ii) App finds top 5 easy meals matching those keywords (sorted by prep time).  
iii) When the user clicks a meal, it expands or opens a card showing:  
* Meal image  
* Estimated time  
* Ingredients  
* Steps / Instructions
